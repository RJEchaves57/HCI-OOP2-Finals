# Project notes

This front-end is a Vite + React + TypeScript SPA. It uses React Router for
routing, Tailwind CSS v4 through `@tailwindcss/vite`, and ESLint (flat config).

- Do not add Next.js-specific APIs or `next/*` imports.
- `"use client"` directives are not needed and should be avoided.
- The Laravel API is external to this repository; do not modify backend code.
- Keep the existing UI markup, class names, and text content unchanged.
